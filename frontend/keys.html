Send traces

      
Already on OpenTelemetry? No code change — set:

      
OTEL_EXPORTER_OTLP_TRACES_ENDPOINT=https://ingest.selenne.app/v1/traces
OTEL_EXPORTER_OTLP_TRACES_HEADERS="Authorization=Bearer <your key>"
OTEL_SERVICE_NAME=<your agent>

      
No OpenTelemetry? Post JSON spans:

      
curl https://ingest.selenne.app/v1/events \
  -H "Authorization: Bearer <your key>" \
  -H "Content-Type: application/json" \
  -d '{"resource":{"service.name":"my-agent"},
       "spans":[{"trace_id":"<32 hex>","span_id":"<16 hex>",
                 "name":"tool.read_file","start_time":"2026-09-29T10:00:00Z"}]}'
