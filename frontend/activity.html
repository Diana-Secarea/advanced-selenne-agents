Activity comes from selenne-sensor, which watches the programs, files and connections your agents use on their hosts.

  1. Run the sensor next to your agents (Linux; Docker, Kubernetes or a VM) with an ingestion key: 
    SELENNE_SENSOR_KEY=sk_sel_… docker compose --profile sensor up -d
  2. Start your agent with its OpenTelemetry service name — that is how the sensor knows it is an agent: 
    OTEL_SERVICE_NAME=my-agent python -m my_agent
